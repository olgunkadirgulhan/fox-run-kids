🦊 Fox Run Kids

Fox Run Kids makes interactive warm-up and obstacle-run videos for children. Kids stand up, run in place, jump, duck and dodge along with an animated fox.

This site describes the publishing tool behind the Fox Run Kids YouTube channel. The tool renders our own original animations and uploads them to our own channel using the YouTube Data API. It does not access any other user's data.
